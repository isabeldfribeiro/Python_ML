## Sobre o projeto

Este projeto utiliza dados sintéticos gerados com auxílio do Claude para explorar a aplicação de técnicas de *Machine Learning* na análise de genomas de *Acinetobacter baumannii*.

Os dados representam isolados provenientes de dois grupos: pacientes com sepse e amostras do meio ambiente. A tabela contém informações sobre a contagem de diferentes categorias de genes e os valores de concentração inibitória mínima (MIC) para o imipenem.

O projeto foi desenvolvido com três abordagens de aprendizado de máquina: classificação, clusterização e regressão.

## Abordagens de Machine Learning

### 1. Classificação

Investigar a capacidade dos algoritmos de classificação de distinguir os genomas de *A. baumannii* provenientes de pacientes com sepse daqueles isolados do meio ambiente, utilizando as características genômicas disponíveis.

### 2. Clusterização

Investigar se os isolados de sepse e do meio ambiente apresentam padrões de agrupamento com base na contagem de genes ou em suas características de presença e ausência, buscando identificar possíveis semelhanças e diferenças entre os grupos.

### 3. Regressão

Avaliar a possibilidade de prever os valores de MIC para o imipenem a partir das características genômicas dos isolados, utilizando algoritmos de regressão.
